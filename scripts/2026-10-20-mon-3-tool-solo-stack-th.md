## Production notes

- B-roll needed: หน้าจอ Cursor พิมพ์ prompt จริง (ไม่ fake), Stripe dashboard โชว์ยอดจริง (เบลอตัวเลขละเอียดได้), Notion workspace layout เลื่อนเร็ว, insert bill เก่า 14 subscription (mock ได้ ให้ดู messy)
- Props: MacBook, จอ external โชว์ dashboard ขวา, มือชู 3 นิ้วตอน close
- จังหวะพูด: VO ไทย ~140 คำ พอดี 60–75s พูดเร็วแต่ชัด ไม่ลาก
- Clean-master export: YES — ไม่มี watermark TikTok, ไม่ layer เพลง TikTok (ตามกฎ repurposing)
- Text on-screen: ฟอนต์ไทยอ่านง่าย (Prompt / IBM Plex Sans Thai) สีขาวตัดพื้นหลัง, ตัวเลข $47 ตัวใหญ่พิเศษตอนปิด
- Hook test: ถ้า retention 3s < 70% สลับเปิดเป็น "ค่า software เดือนละ $47 รัน solo business ทั้งก้อน — stack 3 ตัวนี้"
