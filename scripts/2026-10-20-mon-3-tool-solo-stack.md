## Production notes
- B-roll needed: Cursor coding session (autocomplete visible), Stripe dashboard with blurred-but-believable numbers, Notion dashboard view (CRM + content calendar + finance tracker).
- Props: Clean desk, single laptop, no second monitor on-screen (visual simplicity = message).
- Tool choice is placeholder — swap Cursor → Lovable/Replit, Stripe → Lemon Squeezy/Polar, Notion → Linear+Google Docs if the user's actual stack differs. Keep the (1) build (2) sell (3) run framing regardless.
- Pricing on-screen should match whatever stack is used — update the "$47/mo" hook text if swapped.
- Clean-master export: YES (no TikTok watermark, no TikTok audio layered in).
- Post native to IG Reels and TikTok separately — do not cross-post the TikTok-watermarked file.
- Captions on-screen must be hard-burned for silent viewers (60%+ on IG).
